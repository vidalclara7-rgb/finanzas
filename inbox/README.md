# inbox

Material de entrada para `/sdd:propose`: capturas, referencias de estilo, notas, un Excel de ejemplo.
`/sdd:propose` lo lee todo antes de preguntar, y no pregunta lo que ya está aquí.

**Nada de esta carpeta se sube al repo** (salvo este README): el repo es público. Está en
`.gitignore` y `python3 kit.py check` falla si algo de aquí entra en git. Aun así, mejor no dejar
datos reales: si hace falta un ejemplo, que sea inventado.
